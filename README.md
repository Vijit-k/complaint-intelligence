# Complaint Intelligence

84 days of learning Python and SQL from zero, in public.

**The question:** What do millions of customer complaints reveal about how
financial companies treat their customers, and how fast they fix problems?

**Data:** US CFPB Consumer Complaint Database (public), plus an India chapter
on insurance grievances (IRDAI annual reports).

**How I work:** one concept a day, used the same day on this project.
One commit and one journal post every day.
